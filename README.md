## 核心项目

### [SenrenTalk](https://github.com/davent10086/SenrenTalk)

一个支持多角色协作、长期记忆、RAG、多模态交互和角色一致性控制的 AI 对话应用。

- 使用 **LangGraph** 编排多智能体对话与角色协作流程，覆盖单聊与多角色群聊场景。
- 结合长期记忆与 **Elasticsearch** 检索，为对话提供可延续的上下文和 RAG 能力。
- 通过 **SSE** 实现流式生成体验，并支持多模态交互与 **TTS** 音频能力。

`Multi-Agent` · `LangGraph` · `RAG` · `Elasticsearch` · `SSE` · `多模态` · `TTS`

### [pomelo-chat](https://github.com/davent10086/pomelo-chat)

一个集即时通信、WebSocket 实时消息、Redis、AI Agent 和 MCP 工具能力于一体的全栈聊天应用。

- 基于 **React + TypeScript** 构建聊天界面，使用 **Node.js + Express** 提供服务端 API。
- 基于 **WebSocket** 实现单聊、群聊等实时消息交互，使用 **MySQL** 持久化核心业务数据，并以 **Redis** 管理实时状态。
- 集成 **LangChain Agent** 与 **MCP**，让聊天应用能够调用受控的工具能力。

`React` · `TypeScript` · `Node.js` · `Express` · `WebSocket` · `MySQL` · `Redis` · `LangChain Agent` · `MCP`
